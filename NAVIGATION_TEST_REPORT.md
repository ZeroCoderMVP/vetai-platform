# Протокол проверки кликабельности и переходов

Дата теста: 2026-03-15
Окружение: local / production start (`next start`)
Тестировщик: Codex
Браузер / устройство: HTTP smoke + code review, без полноценного интерактивного браузера
Роль пользователя: без авторизации / full access MVP
Ссылка на стенд: `http://127.0.0.1:3000`
Общий статус: PARTIAL

## Методика

- Проверены реальные маршруты приложения через локальный запуск и HTTP-ответы.
- Проверены реализованные переходы по исходному коду (`Link`, `router.push`, `window.location.href`).
- Проверка сохранения контекста выполнена по коду компонентов фильтрации и навигации.
- Ограничение: role-based сценарии и полноценные клики в браузере не покрыты, так как в окружении не был доступен готовый browser runtime для end-to-end прогона.

## Быстрые факты

- `200 OK`: `/dashboard`, `/events`, `/herd`, `/herd/21`, `/health`, `/reproduction`, `/feeding`, `/milking`, `/video`, `/operations`, `/operations/performance`, `/operations/cmmp5dbch00027sdcv8s3gfd9`, `/reporting`, `/reporting/reports/cmmoo72hd0000x8dcrisbveh6`, `/reporting/templates`, `/admin`
- Некорректные динамические ID тоже отдают `200 OK`: `/herd/999`, `/operations/does-not-exist`, `/reporting/reports/does-not-exist`
- Реально реализованные переходы:
  - dashboard KPI -> `/milking`, `/feeding`, `/herd`, `/health`, `/reproduction`, `/video`
  - herd row -> `/herd/:id`
  - events row -> `/herd/:id`
  - operations row -> `/operations/:id`
  - operations -> `/operations/performance`
  - reporting card -> `/reporting/reports/:id`
  - global search -> pages + cows only
