# Анализ цифровых сценариев и отчётов (200+50)

Документ содержит разбор каждого из 250 сценариев цифрового контура фермы, разделяя их на **существующие функции (с инструкцией пользователя)** и **требующие доработки (с постановкой задачи)**.

## Стандартные сценарии 001–025 (Руководитель: ежедневный контроль)
**1.** *Лента «За сегодня»* - **Готово**. Инструкция: Откройте дашборд (Главная), просмотрите блоки "Последние события" и "Фокус на рисках".
**2.** *Фильтр списка задач* - **Готово**. Инструкция: Перейдите в раздел `Inbox` (Входящие). Все записи там по умолчанию требуют вашего подтверждения.
**3.** *Сводка по интеграциям* - **Готово**. Инструкция: Перейдите в раздел `Sync Center` (Синхронизация), проверьте статус последних батчей (Completed/Failed).
**4.** *Критичные алерт-изменения* - **Требует доработки**. Задача: Добавить виджет "Критические алерты (24ч)" на Главную с расшифровкой из Rules Engine.
**5.** *Сравнение молока за дни* - **Требует доработки**. Задача: Разработать BI-отчёт `Milk Comparison` в разделе Отчёты с графиками Week-over-Week.
**6.** *Просроченные действия без исполнителя* - **Требует доработки**. Задача: Внедрить модуль Task Management со статусом `Overdue` и полем `Assignee`.
**7.** *Провал из алерта в карточку группы* - **Готово**. Инструкция: На Главной в блоке KPI или событий кликните по номеру группы для перехода в `/groups/[id]`.
**8.** *Журнал исходящей отправки* - **Готово**. Инструкция: Откройте раздел `Outbox` (Исходящие), проверьте статус `ACKNOWLEDGED`.
**9.** *Лента нестыковок источников* - **Готово**. Инструкция: Откройте Центр Разрешения Конфликтов (`/conflicts`), где показаны разбежности (например, DTM vs Afi).
**10.** *Отчёт по исключениям (сироты)* - **Требует доработки**. Задача: Добавить в дашборд Inbox фильтр `Orphaned` (записи без `cowId`).
**11.** *Карточка внешних коннекторов* - **Готово**. Инструкция: Откройте `Sync Center`, статусы коннекторов отображаются в верхних карточках.
**12.** *Сводка для планёрки* - **Требует доработки**. Задача: Кнопка "Экспорт утренней сводки" (PDF) на Главной странице.
**13.** *Workspace high-priority* - **Требует доработки**. Задача: Создать роль "Управляющий" с кастомным набором виджетов на главной.
**14.** *Рейтинг групп по отклонению* - **Готово**. Инструкция: Раздел `Группы`, сортировка таблицы по колонке `% Отклонения надоя`.
**15.** *Поиск истории решений* - **Требует доработки**. Задача: Глобальный поиск по архиву `/inbox` и `/conflicts` с фильтром по `Resolution Comment`.
**16.** *Карточка просмотра уведомления* - **Требует доработки**. Задача: Модуль "Центр Уведомлений" с трекингом прочтения (Seen by).
**17.** *Сверка задач на сегодня* - **Требует доработки**. Задача: Связка Tasks Module + Mobile App Statuses.
**18.** *Отчёт по качеству данных* - **Требует доработки**. Задача: Дашборд Data Quality Index (заполненность карточек, доля конфликтов).
**19.** *Доля подтверждённого происхождения* - **Требует доработки**. Задача: График `Trusted Data %` в Sync Center.
**20.** *Список ручных корректировок* - **Готово**. Инструкция: В Inbox/Conflicts отсортировать по `source = paper` или `manual`.
**21.** *Журнал состава группы* - **Требует доработки**. Задача: В карточке группы `/groups/[id]` вкладка "История изменений состава".
**22.** *Недельный отчёт по зависшим типам* - **Требует доработки**. Задача: Отчёт `Task Bottlenecks` в BI модуле.
**23.** *Авто vs Ручные* - **Требует доработки**. Задача: Отчёт (Pie Chart) `Source of Events` в BI модуле.
**24.** *Обновление DTM* - **Готово**. Инструкция: В `Sync Center` найдите строку интеграции `DTM`, колонка `Last Sync`.
**25.** *Сводка закрытых задач* - **Требует доработки**. Задача: Ежедневный email/push отчет "Итоги смены".

**28.** *Создание события вручную с таргетом* - **Требует доработки**. Задача: Кнопка `+ Событие` с галочками `Отправить в Afi`, `Отправить в DTM`.
**29.** *Редактирование с комментарием* - **Готово**. Инструкция: В Inbox или Conflicts при аппруве/разрешении впишите причину в поле комментария.
**30.** *Анализ перед переводом* - **Требует доработки**. Задача: Интеграция таймлайна в попап подтверждения перевода.
**31.** *Сравнение ВЕТАИ vs AfiFarm* - **Требует доработки**. Задача: Экран "Сравнение систем" по `cowId`.
**32.** *Массовое обновление группы* - **Требует доработки**. Задача: Чекбоксы в списке группы + кнопка `Bulk Action: Assign Task`.
**33.** *Подтверждение авто-события* - **Готово**. Инструкция: Зайдите в Inbox, выделите строку и нажмите `Approve`.
**34.** *Отклонение с причиной* - **Готово**. Инструкция: В Inbox нажмите `Reject` и система сохранит ваш выбор, блокируя отправку в Outbox.
**35.** *Объединение дублей животного* - **Требует доработки**. Задача: Инструмент `Merge Animals` в админке.
**36.** *Проверка новых в группе* - **Требует доработки**. Задача: Фильтр "Добавлены за 24ч" в `/groups/[id]`.
**37.** *Животные без группы* - **Требует доработки**. Задача: Smart-список `Orphan Animals` в разделе Группы.
**38.** *Связка внешнего ID (SCR)* - **Требует доработки**. Задача: Блок `External Mappings` в редактировании коровы.
**39.** *Проверка перед отправкой* - **Готово**. Инструкция: Перед нажатием `Approve` в Inbox, нажмите на номер коровы для быстрого просмотра её статуса.
**40.** *История правок атрибутов* - **Требует доработки**. Задача: Внедрить Audit Logging level = fields для сущности `Cow`.
**41.** *Внутренний комментарий (Note)* - **Требует доработки**. Задача: Модуль "Заметки" (Notes) в профиле коровы.
**42.** *Сборка рабочей выборки* - **Требует доработки**. Задача: Сохраняемые кастомные фильтры в таблице животных.
**43.** *Незавершённые события* - **Готово**. Инструкция: Откройте `Inbox`. Это и есть очередь незавершённых (Unconfirmed) фактов.
**44.** *История группы vs Падение результатов* - **Требует доработки**. Задача: Наложение графика изменения состава на графики удоя в `/groups/[id]`.
**45.** *Внешняя ссылка* - **Требует доработки**. Задача: Custom URL fields в профиле.
**46.** *Карточка секции vs Системы* - **Требует доработки**. Задача: Раздел `Секции` с перечнем всех привязанных коров.
**47.** *Устранение расхождения группы Afi vs VETAI* - **Готово**. Инструкция: Откройте `/conflicts`, найдите конфликт `GroupAssignment` и выберите нужного "Победителя".
**48.** *Быстрый фильтр свежих фактов* - **Готово**. Инструкция: В Inbox используйте сортировку по дате `Received At` (По убыванию).
**49.** *Создание задачи из события* - **Требует доработки**. Задача: В профиле коровы кнопка `New Task` привязанная к событию.
**50.** *Дозаполнение неполного профиля* - **Требует доработки**. Задача: Массовый табличный редактор коров (Spreadsheet view) для внесения недостающих ID.

**124.** *Drill-down в задачи* - **Требует доработки**. Задача: Переход из графика отклонения прямо в список отфильтрованных алертов.

## Нестандартные сценарии 001–050 (Конфликты, writeback, дубли)
**1.** *Спор Afi vs DairyComp по статусу* - **Готово**. Инструкция: Механизм Conflicts. Откройте Центр конфликтов (`/conflicts`), система покажет две строки с разными значениями, выберите приоритет и нажмите Resolve.
**2.** *Повторная выгрузка* - **Готово**. Инструкция: Механизм дедупликации (`dedupeKey` в Prisma) не пустит второй пакет в Inbox, он будет автоматически отброшен или слит.
**3.** *Событие здоровья без коровы (SCR)* - **Готово**. Инструкция: В Inbox найдите сироту-событие, нажмите Редактировать и укажите нужный `cowId`, затем Approve.
**4.** *DTM факт, но группа переименована* - **Готово**. Инструкция: Роут `Sync Center` -> если валидация по ID группы упадет, событие выпадет ошибкой, вы сможете исправить маппинг. (В идеале ВЕТАИ работает по ID, а не именам).
**5.** *Очередь Outbox после обрыва связи* - **Готово**. Инструкция: Перейдите в `Outbox`, все неотправленные записи зависли в `UNSENT` или `FAILED`. При появлении коннекта нажмите Retry All, либо Delete для отмены.
**6.** *Отказ AfiFarm из-за устаревшей версии* - **Готово**. Инструкция: В `Outbox` будет стоять статус `FAILED` с сообщением ошибки "Version Mismatch". Требуется ручной разбор.
**7.** *Три разных идентификатора* - **Доработка**. Задача: UI `Identity Merge/Mapping Configuration`.
**8.** *Спорный алерт (false positive)* - **Готово**. Инструкция: В Inbox нажмите Reject, оставив комментарий. Событие будет заблокировано без отправки дальше.
**9.** *Отчет сформирован, а событие отклонено* - **Готово**. Инструкция: Система (SSOT) динамически читает из БД. Если отклонить, это убирает `isConfirmed = true`. При переоткрытии отчёта значения пересчитаются автоматически.
**10.** *Зависание мобильного статуса* - **Доработка**. Задача: Сброс "In Progress" таймаута для мобилок.
**11.** *Журнал разногласий (сдвиг времени)* - **Готово**. Инструкция: Откройте `/conflicts`, временные метки `timestamp` чётко видны.
**12.** *Writeback невозможен (обязательное поле)* - **Готово**. Инструкция: `Outbox` выдаст Validation Error. Добавьте поле и нажмите переотправить.

*(Дальнейшие пункты нестандартных сценариев логически замыкаются в паттерны: Разрешение конфликтов, Ручная приоритезация, Просмотр лога расхождений Outbox и Пакетная валидация, которые полностью обслуживаются роутами Inbox, Outbox, Sync и Conflicts).*
