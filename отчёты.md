Стратегия: создать набор кастомных отчётов, покрывающих все ключевые области данных
В AfiFarm через Build New Reports (Dashboard → New → Cow → Next) вы создаёте свои отчёты, выбирая колонки (Available Titles) и триггеры/фильтры (Triggers) для включения/исключения животных. Чтобы выгрузить всё для аналитики, нужно создать несколько отчётов, каждый из которых покрывает свой блок данных.

Отчёт 1: Продуктивность (Надои)
Перейдите в Available Titles и добавьте колонки из категории Milk Production:
— Index, Cow ID, Tag, Group name, Lactation number, DIM (дни в молоке), Daily Yield (Today, Avg), Milk per session (1-я, 2-я, 3-я дойки), Peak Milk, 305-day Yield, Lactation Yield, Fat %, Protein %, Lactose (если есть AfiLab), SCC (соматические клетки), Conductivity, Milk Curve deviation indicators.
Триггер: All Animals → Status = Milk (чтобы получить всех дойных коров).

Отчёт 2: Фертильность и репродукция
Колонки из категории Fertility:
— Cow ID, Gynecological Status, Days Pregnant, Insemination date, Insemination number, Bull name, Heat events, Heat index/intensity, Voluntary Waiting Period, Days to first insemination, Conception Rate, Expected Calving Date, Pregnancy Check date/result, Suspected Abortion status.
Триггер: All Animals (коровы + тёлки), без исключений — чтобы видеть полную картину фертильности.

Отчёт 3: Здоровье
Колонки из категории Health:
— Cow ID, Mastitis indicators, Digestion Problems indicators, Ketosis indicators, Non-Specific Health alerts, Animals in Distress status, Diagnosis codes/comments, Treatment history, Fresh Cow check status.
Триггер: All Animals.

Отчёт 4: Благополучие (Welfare) и активность
Колонки из AfiCollar/AfiAct данных:
— Cow ID, Activity level, Rumination time (мин/день), Eating time, Rest time, Rest bouts, Activity deviation, Sorted animal status.
Триггер: All Animals.

Отчёт 5: Классификация и инвентарь стада
Колонки из Animal Parameters / Classification:
— Cow ID, Breed, Birth Date, Age, Lactation number, Status (Milk/Dry/Heifer/Parking), Group, Herd, Entry date, Calving date, Dry date, Code flags.
Триггер: All Animals (включая сухостойных, тёлок и т.д.).

Отчёт 6: Кормовая эффективность (Feed Efficiency)
Если у вас есть модуль Feed Efficiency:
— Cow ID, Feed Efficiency index, Income Over Feed Cost, DIM range, Breeding Decision, Culling recommendation.

Как автоматизировать выгрузку
Используйте функцию Automatic Schedule (Tools → Schedules → New):

Добавьте каждый из созданных отчётов в планировщик.
В поле Action выберите Save (сохранение в файл — CSV/Excel).
В поле Target укажите сетевую папку или локальную директорию для выгрузки.
Установите расписание — ежедневно после последней дойки (или по сессиям).

Это даст вам автоматическую ежедневную выгрузку файлов, которые можно подключить к Power BI, Tableau или любому другому инструменту для дашборда.

Практические советы
Организация: Создайте в My Folders отдельную папку (например, «Analytics Export») и складывайте туда все эти отчёты — так они не потеряются среди стандартных.
Trigger = без фильтров: Для максимальной выгрузки ставьте триггер "All Animals" или отключите триггер (Disable Trigger) — тогда в отчёт попадут все коровы без исключений.
Limit Report Tool: Не используйте его при создании «сырых» отчётов для аналитики — фильтрацию лучше делать уже на стороне дашборда.
Экспорт: Из любого готового отчёта в AfiFarm можно правой кнопкой мыши экспортировать данные в Excel/CSV. Но для регулярной аналитики лучше настроить Automatic Schedule.
