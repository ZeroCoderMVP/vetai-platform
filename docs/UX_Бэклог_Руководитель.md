# UX Бэклог: Руководитель (Директор / Управляющий)

## Stage 1: Базовый мониторинг (Read-only)
- **Сводки и Отчеты:** Просмотр аналитики "Производство за сутки" (сверка удоя AfiFarm и факта DTM). Базовые отчеты по дню по сырым данным SQLite.
- **Карта фермы и Списки:** Визуализация секций с наличием проблем. Карточка проблемной группы (доение, здоровье) в виде простых таблиц.

## Stage 2: Контроль потоков данных (Routing)
- **Журнал интеграций:** Просмотр статусов загруженных батчей (Afi, DTM) через панель Sync Center.
- **Контроль Writeback и Конфликтов:** Панель Outbox (мониторинг застрявших отправок). Обзор экрана Conflicts для разбора системных споров (например, DairyComp vs AfiFarm).
- **Политики данных:** Утверждение маппингов и выбор "источника истины" для конфликтов.

## Stage 3: Дашборды, Задачи и Аналитика (BI & Tasks)
- **Рабочее место Руководителя:** Кастомный Дашборд "За сегодня" с KPI по персоналу (% закрыто вовремя, % зависло). Список эскалированных задач.
- **Распределение задач (Task Engine):** Назначение исполнителей на аномальные алерты.
- **Стратегический BI:** Data Quality Index (Индекс чистоты данных), тепловые карты секций, отслеживание доли ручного ввода.
- **UX симуляции:** Расчеты "what-if" и тестирование новых модулей.
