# UX Бэклог: Кормление (Кормленец / Руководитель кормления)

## Stage 1: Анализ факта кормления (Read-only)
- **План-Факт загрузки:** Базовый просмотр таблиц загрузки из DTM в сравнении с размером группы из AfiFarm.
- **Отчеты по остаткам:** Простые выгрузки и сверки потребления сухого вещества по секциям / рационам.

## Stage 2: Корректировки и Конфликты (Routing & Resolution)
- **Управление Маппингами (Conflicts):** Разрешение конфликтов названий групп, связывание новых кодов DTM с внутренними кодами ВЕТАИ.
- **Правила приоритета:** Настройка системы на безусловное использование DTM как "источника истины" для кормовых фактов поверх AfiFarm.
- **Подтверждения (Inbox):** Отметка факта догрузки (второй проезд).

## Stage 3: Дашборды и Интеграция Оборудования (Workspace & Tasks)
- **Рабочее место "Кормление":** Продвинутый дашборд с визуальным анализом разбежностей факта потребления и изменения удоев (Timeline overlays).
- **Мобильный DTM Flow:** Подключение к весам миксера с мобильного устройства ВЕТАИ, корректировки рецептов "на лету" с офлайн-поддержкой.
- **Оркестрация задач:** Генерация заданий складу при падении остатков критичного компонента.
