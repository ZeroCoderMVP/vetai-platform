# UX Бэклог: Оператор данных (Специалист по интеграциям)

## Stage 1: Базовый мониторинг пайплайнов
- **Статус импортов:** Просмотр времени последней синхронизации коннекторов (AfiFarm, DTM, AIC, SCR).
- **Журналы ошибок:** Доступ к сырым логам API и файлов для копирования подрядчикам.

## Stage 2: Управление Роутами и Конфликтами (Core Routing)
- **Управление Outbox / Inbox:** Повторный ручной перезапуск застрявших пакетов (Manual Retry), прочистка ошибок пакетов, массовое одобрение.
- **Разрешение конфликтов (Conflicts Center):** Использование инструмента слияния животных (Identity Merge) при рассинхронах баз, комбайн событий (Event Merge). 
- **Тумблеры (Sync Center):** Отключение отдельных коннекторов при проведении регламентных работ во внешних системах.

## Stage 3: Аналитика Качества и Правила (Tasks & BI)
- **Data Quality Index (BI):** Мощный дашборд-светофор по качеству коннекторов, расчет "индекса мусора".
- **Rule Engine & Откаты:** Кнопки мягкого удаления всего недавнего батча (Undo Batch). Глобальный поиск (Omnisearch) для расследования пути прохождения кривой записи от интеграции до дашборда.
