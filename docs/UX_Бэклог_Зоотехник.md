# UX Бэклог: Зоотехник

## Stage 1: Воспроизводство и структура стада (Read-only)
- **Списки "в охоте":** Базовый просмотр списка коров, сформированного по импорту (AfiFarm/SCR).
- **Отчеты и сверки:** Базовые недельные выгрузки, выявление животных, вышедших за протокол.
- **Карточка коровы:** Просмотр исторической таблицы сырых событий воспроизводства (отёлы, осеменения).

## Stage 2: Ввод данных и Маршрутизация (Routing / Outbox)
- **Ввод фактов:** Внесение отметки об осеменении или переводе животного в новую группу через веб-форму (Inbox поток).
- **Контроль Writeback (Outbox):** Проверка успешности отправки своих введенных событий обратно в AfiFarm, предотвращение дублей.

## Stage 3: Мобильное Рабочее Пространство и Задачи (Tasks)
- **Рабочее место "Воспроизводство":** Полноценная очередь скоординированных задач (кого осеменять, кого переводить, дедлайны).
- **Мобильный контур:** Отметка событий на мобильном устройстве прямо у станка (учет офлайн-буферизации, сканирование бирок).
- **Таймлайны и Автоматизация:** Единая лента-хроника по животному (Timeline). Пакетное закрытие задач после утреннего обхода (Bulk Actions).
- **Исключения:** Временное отключение автоматических задач для пилотных групп.
