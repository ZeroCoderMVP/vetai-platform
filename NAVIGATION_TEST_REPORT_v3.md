## Методика

- Проанализированы текущие маршруты приложения (`src/app/**/page.tsx`).
- Перестроены интерфейсы с помощью `useSearchParams` и `Suspense` для консистентной передачи параметров в URL.
- Сверены требования из предыдущего протокола (v2) с текущим состоянием кодовой базы и проведен локальный билд (`npm run build`).

## Быстрые факты

- Периоды (`dateFrom` / `dateTo`) теперь синхронизируются через URL query params и сохраняются при переходах между экранами.
- На дашборде реализованы переходы в профили животных, страницы групп и раздел отчетности. 
- Динамические маршруты теперь обрабатывают отсутствующие данные через глобальный механизм `not-found.tsx`.
- Глобальный поиск (`CommandPalette`) расширен: теперь находит события и группы вместе с коровами и страницами.
- Группа "Телята" (Молодняк / Нетели) выведена в навигацию с передачей `?type=calves`.
- Ошибки компиляции TypeScript, связанные с изменениями параметров в Next.js 15+ и типами, успешно разрешены.
