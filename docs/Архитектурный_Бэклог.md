# Архитектурный Бэклог (Core & Data Foundation)

Этот бэклог закладывает фундамент данных и интеграций, обеспечивая единую терминологию и подходы.

## Stage 1: Базовая модель и однонаправленный импорт
- Единая модель данных (SQLite): `Cow`, `Group`, `Section`, `Barn`, `Event` и др.
- Стабильные внутренние ID (GUID/Int) и привязка к `afiId`.
- Ingestion Pipeline: Загрузчики для `inbox/afimilk`, `inbox/dtm`, `inbox/aic`.
- Стабильный роутинг: `/[entity]/[id]`.
- Отказ от mock-данных на базовых экранах.

## Stage 2: Двунаправленная маршрутизация (Data Routing)
- Управление валидацией (Inbox): Подтверждение входящих фактов от персонала.
- Слой Конфликтов (Conflict Resolution): Разрешение споров данных, слияние животных.
- Инфраструктура Writeback (Outbox): Обратная отправка во внешние системы с механизмом повторов (Retry Engine).
- Sync Center: Управление батчами и коннекторами (остановка/отмена/аудит).

## Stage 3: Оркестрация, Задачи и BI (UX Layer)
- Слой Оркестрации (Task Engine): Маршрутизация проверенных данных из Inbox в операционные задачи.
- Mobile API & Offline: Проброс офлайн-меток, синхронизация при появлении сети.
- Уровни BI: Глобальный поиск, тепловые карты, глубокие карточки с таймлайнами, ролевые дашборды.
