# 6. Видео как резервный источник при нехватке данных

Видео не заменяет системные данные по молоку, кормам, экономике и истории группы. Но оно может закрыть отдельные слепые зоны, если других источников нет или они неполны.

| Сценарий | Что реально можно получить | Ограничения | Рекомендация |
| --- | --- | --- | --- |
| Хромота (lameness) | Ежедневный mobility/locomotion score, алерты по ухудшению походки | Нужна камера в узком проходе/на выходе из доильного зала и связка с ID коровы | Годится как отдельный сервис, не как костыль внутри Stage 1 |
| Упитанность (BCS) | Регулярный body condition score по проходу коровы под камерой | Нужна стабильная точка съёмки, ID linkage и проверка модели на вашем типе стада | Полезно как параллельный контур наблюдений |
| Наличие/проход коров | Факт прохождения через точку, частично — occupancy/traffic | Без RFID/ID linkage даёт слабую ценность для аналитики по конкретной корове | Не использовать как замену history membership |
| Молоко/корм/экономика | Ничего надёжного | Видео не измеряет валовый надой, выпойку, продажу, загрузку ингредиентов как source of truth | Не рассматривать как замену AFI/DTM/ручным потокам |

Практически возможный внешний сервис: camera-based monitoring на базе обычной security camera на выходе из доильного зала. Такой контур уже существует на рынке и закрывает mobility + BCS, но не молоко/корма/экономику.

# 7. Рекомендуемое решение по приоритетам

1. Уже сейчас можно запускать SQLite-first контур на AFI DAY_MILK + AFI JSON + текущем DTM + AIC как детализации дня.
1. Считать AFI DAY_MILK основным источником валового дневного надоя и истории по корове за период. AIC использовать только для дня.
1. Для milk balance сразу вводить отдельные ручные/внешние потоки: milk_sold, milk_calves, milk_loss, milk_revenue.
1. Для групповой молочной аналитики в Stage 1 честно зафиксировать режим «приближённо по текущему или восстановленному составу группы», пока не получена история membership.
1. Первым запросом на доп. выгрузку сделать именно историю «корова → группа/секция → дата»; это самый ценный недостающий слой.
1. Видеоаналитику по хромоте и BCS можно вести как параллельный пилот, но не включать её в критический путь Stage 1.
