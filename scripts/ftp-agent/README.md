# Агент-Загрузчик Данных (VETAI Data Agent)

Этот скрипт-агент предназначен для локального компьютера (например, на ферме), чтобы автоматически отслеживать появление или изменение файлов (отчёты DTM, Afimilk, и т.д.) в নির্দিষ্ট парите и отправлять их по **FTP**.

## Преимущества
* **Не требует установки** сторонних программ (Python, Node.js). Написан на PowerShell, который встроен во все версии Windows.
* **Автоматически запускается** вместе с Windows в фоновом режиме.
* **Отслеживает изменения:** ведет локальную мини-базу `agent_state.json`. Если вы закинули новый файл, или файл был перезаписан с другим временем/размером — агент берет его и отправляет.
* **Устойчив:** ждет, пока файл полностью перестанет редактироваться (если сторонняя программа еще записывает его на диск), прежде чем начать отправку.

## ⚙️ Настройка

1. Откройте файл `Agent-Sender.ps1` в стандартном приложении **Блокнот** или любом редакторе.
2. В самом начале скрипта найдите блок **НАСТРОЙКИ** и поменяйте их под ваши реалии:
   - `$SourceFolder = "C:\DataToUpload"` — Укажите папку, которую агент должен прослушивать. 
   - `$FtpServer = "ftp://ваш-сервер/папка"` — Адрес вашего FTP сервера для загрузки.
   - `$FtpUsername` и `$FtpPassword` — Доступы к FTP.
   - `$CheckIntervalSeconds = 60` — Как часто опрашивать папку (в секундах).

## 🚀 Как установить в автозагрузку (Автоматический старт)

1. Откройте папку со скриптами в проводнике.
2. Нажмите правой кнопкой мыши по файлу `Install-Agent.ps1`.
3. В контекстном меню выберите **«Выполнить с помощью PowerShell»** (Run with PowerShell).
4. Если система спросит разрешения — нажмите "Y" (Да).
5. На экране появится зеленое сообщение об успешной установке.

С этого момента при каждом включении компьютера (входе в учетную запись) будет незаметно стартовать задача, которая постоянно мониторит папку и загружает файлы.

## 📝 Логи и работа
В папке со скриптом будут автоматически создаваться два файла:
* `agent.log` — журнал работы. Откройте, чтобы посмотреть, когда и какие файлы отправлялись на сервер.
* `agent_state.json` — технический файл памяти агента (чтобы не отправлять одни и те же старые файлы по второму кругу).

## 🛑 Как остановить агента?
Если вам нужно навсегда выключить агента:
1. Нажмите меню `Пуск` -> `Планировщик задач` (Task Scheduler).
2. В списке задач (Библиотека планировщика) найдите задачу **VETAI_Data_Agent**.
3. Нажмите по ней правой кнопкой мыши -> **Удалить** (или **Отключить**).
