# UX Бэклог: Ветврач

## Stage 1: Мониторинг здоровья (Read-only)
- **Списки здоровья:** Таблицы животных с предупреждениями (SCR/AfiFarm). Сводки по свежим коровам.
- **Карточка коровы:** Просмотр сырых данных (лечение, надой, conductivity) без редактирования.
- **Подготовка к обходу:** Выгрузка списка животных с подозрением на мастит.

## Stage 2: Регистрация фактов и Маршрутизация (Routing / Outbox)
- **Ввод лечения:** Внесение в систему факта лечения (препарат, доза, дата).
- **Валидация (Inbox):** Сопоставление ручного ввода с автоматическим алертом системы (связывание событий).
- **Контроль Writeback (Outbox):** Отправка подтвержденного лечения в herd-management систему, контроль статуса доставки. Отклонение ложных сигналов мастита по Waikato.

## Stage 3: Дашборды, Задачи и Анализ (Tasks & BI)
- **Рабочее место "Здоровье":** Дашборд с приоритизацией списков, назначенные на ветврача задачи (дедлайны, сабтаски).
- **Мобильный контур:** Ввод статуса осмотра в приложении прямо у животного (буферизация при потере сети).
- **Глубокий аудит:** Журнал изменений по корове (кто поменял диагноз), отложенный writeback. Пакетное закрытие задач.
