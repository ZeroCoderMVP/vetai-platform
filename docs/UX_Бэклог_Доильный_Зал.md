# UX Бэклог: Менеджер доильного зала / Оператор доения

## Stage 1: Мониторинг сессий (Read-only)
- **Рабочий список зала:** Просмотр таблиц отклонений доения (из Waikato/AfiMilk).
- **Отчеты по сессиям:** Примитивная выгрузка результатов смены (потери времени, сбои идентификации коровы).

## Stage 2: Регистрация фактов и Удержание (Routing)
- **Управление Inbox:** Ввод (исправление) неверной идентификации животного (cowId) после сессии, подтверждение системной подсказки.
- **Отправка данных (Writeback):** Отметка животного на ручном удержании и отправка этого факта в систему управления стадом (AfiFarm).

## Stage 3: Терминалы и Взаимодействие (Tasks & Terminals)
- **Терминальный UI:** Крупногабаритный, упрощенный интерфейс для зала, позволяющий делать 1-клик отметки проблем в перчатках.
- **Интеграция с Task Engine:** Кнопки мгновенного генерирования задач ветврачу по высокому conductivity прямо из терминала. 
- **Аналитика:** Ролевые push-уведомления об аномалиях всей группы.
