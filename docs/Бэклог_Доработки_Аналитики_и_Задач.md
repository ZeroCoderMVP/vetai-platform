# Бэклог доработок Управления, Аналитики и Профилей (Stage 3+)

Этот бэклог содержит задачи по созданию BI-аналитики, карточек и координации персонала (Task Management), которые строятся поверх надежного слоя маршрутизации данных (Inbox/Conflicts/Outbox).

## 1. Развитие модуля "Таск-трекер" (Task Engine)
Полноценная система распределения задач поверх очищенных событий `Event` из Inbox:
- [ ] **Жизненный цикл задачи.** Добавление статусов `IN_PROGRESS` (в работе), `PENDING_INFO` (ожидает данных).
- [ ] **Назначение исполнителей (Assignees & Escalation).** Поля `assigneeId` для распределения работы внутри смены. Кнопка `Escalate to Manager`. Фильтры "Только мои задачи".
- [ ] **Контроль дедлайнов (Due Dates).** Возможность поставить срок выполнения задачи. Переход в статус `OVERDUE` при просрочке.
- [ ] **Сабтаски и Follow-ups.** Кнопка "Создать задачу из события" для генерации связанных действий (например, "Контрольный осмотр через 48ч").
- [ ] **Медиа-вложения (Attachments).** Прикрепление файлов (фото бланка/УЗИ) к задаче.

## 2. Кастомные Ролевые Workspace (Дашборды по ролям)
Разделение интерфейса на специализированные рабочие пространства:
- [ ] **Рабочее место Руководителя.** Виджеты "Критические изменения за 24 ч" (High-priority risks) и эскалированные задачи. Ролевые Push-уведомления об аномалиях.
- [ ] **Рабочее место Ветврача (Health Workspace).** Очередь задач, отфильтрованная исключительно по типам Репродукство/Здоровье.
- [ ] **Рабочее место Кормленца (Feed Workspace).** Анализ разбежностей планируемого и фактического (DTM) потребления корма.
- [ ] **Терминальный UI для Доильного Зала.** Упрощённый планшетный интерфейс с крупными кнопками для операторов доения.
- [ ] **Утренние экспорт-сводки (PDF Reports).** Генерация сводки на планёрку (ключевые метрики ночной смены и планы на день).

## 3. Карточки животных (Cow Card) и Групп (Group Card)
Апгрейд карточек до центров принятия решений (SSOT):
- [ ] **Вкладка Таймлайн (Timeline / Journal).** Единая лента-хроника по животному/группе: здоровье, переводы по секциям, изменения рационов и история конфликтов данных.
- [ ] **Режим полного редактирования (Edit Mode).** Возможность вручную исправить базовые атрибуты животного, пришедшие пустыми.
- [ ] **Пополевой аудит (Audit Logging Level).** Иконка "история" возле критичных атрибутов (например, порода), показывающая, кто именно изменил поле на стороне ВЕТАИ.
- [ ] **История изменения состава (Group Roster History).** Наложение графика переводов животных `In/Out` на график надоя группы.
- [ ] **Внутренние Заметки (Notes).** Виджет свободных текстовых комментариев к корове.

## 4. Продвинутая Аналитика и Поиск (BI & Data Quality)
- [ ] **Глобальный поиск (Omnisearch).** Поисковая строка в шапке (Ctrl+K) для моментального поиска по номеру коровы, `afiId` или ID внешней системы.
- [ ] **Data Quality Index (Индекс чистоты данных).** Отчёт, показывающий какой % событий прилетает с ошибками, дублируется или отклоняется людьми. Светофор по коннекторам.
- [ ] **Отчёт "Время жизни задачи" (Time-to-resolution).** Анализ скорости реакции персонала: сколько часов висит подозрение на мастит до подтверждения.
- [ ] **Тепловая карта секций (Section Heatmap).** Визуализация карты коровников с подсветкой скоплений больных коров или просроченных задач.
- [ ] **Доля ручного ввода (Manual Entry Ratio).** Метрика уровня цифровизации фермы — % фактов, внесенных через Paper Inbox или полностью руками.

## 5. Специфические механики
- [ ] **Проброс Офлайн-меток (Timestamp buffering).** Корректная обработка таймстемпов офлайн-ввода в мобильном контуре для сохранения правильного порядка "событие-последствие".
